# 🧭 MGNREGA Karnataka Analytics Dashboard

This project visualizes the performance of Karnataka’s districts under the **Mahatma Gandhi National Rural Employment Guarantee Act (MGNREGA)** using Python, Plotly, and Dash.

---

## 📊 Features
- Data cleaning and transformation using **Pandas**
- Interactive visualizations built with **Plotly Dash**
- District-level analysis for **FY 2023–24**
- Exported offline dashboard as HTML
